# Galeria de Fotos

Aplicação web responsiva para visualização e pesquisa de imagens, desenvolvida com **React, Next.js, TypeScript e Tailwind CSS**.

O projeto foi criado com foco em componentização, responsividade e uma experiência simples de navegação, permitindo filtrar as imagens em tempo real pelo título.

## Demonstração

A aplicação está disponível em:

https://galeria-fotos-rho-two.vercel.app/

## Funcionalidades

- Exibição de imagens em layout responsivo
- Pesquisa em tempo real pelo título das fotos
- Mensagem quando nenhum resultado é encontrado
- Efeito visual ao passar o cursor sobre os cards
- Componentes reutilizáveis
- Layout adaptado para diferentes tamanhos de tela

## Executando localmente

Clone o repositório:

```bash
git clone https://github.com/Ppedro-Leal/Galeria_Fotos.git
```

Acesse o diretório do projeto:

```bash
cd Galeria_Fotos
```

Instale as dependências:

```bash
npm install
```

Execute o ambiente de desenvolvimento:

```bash
npm run dev
```

A aplicação estará disponível em:

```text
http://localhost:3000
```
